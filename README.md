# 🎓 Virtual Campus Tour

An immersive 360° Virtual Campus Tour created using the Panoee platform.

## 📌 About the Project

Virtual Campus Tour is an interactive 360° virtual tour that allows users to explore the college campus digitally.

The project provides an immersive experience where users can move from one campus location to another using interactive hotspots. Each location includes its name and relevant images to help users understand the campus environment.

The virtual tour can be accessed through a web browser and can also be viewed in Fullscreen and VR modes.

## 🎯 Objective

The main objective of this project is to provide students, parents, visitors, and guests with an easy and interactive way to explore the college campus virtually without physically visiting every location.

## ✨ Key Features

- 🌐 Interactive 360° campus view
- 📍 Hotspot-based navigation
- 🏫 Location names displayed on hotspots
- 🔄 Navigation between different campus locations
- 🖼️ Additional images for locations
- ⛶ Fullscreen viewing
- 🥽 VR mode support
- 💻 Browser-based access
- 🔗 Shareable virtual tour

## 🛠️ Platform & Tools Used

- Panoee
- iPhone Panorama (PANO) Mode
- Web Browser
- VR Mode

## 📷 360° Image Capture

The 360° panoramic images used in this project were captured using an iPhone with the built-in Panorama (PANO) mode.

These panoramic images were then uploaded and arranged using the Panoee platform to create the virtual campus tour.

## 🔄 Project Workflow

1. Capture panoramic images of different campus locations using an iPhone.
2. Upload the panoramic images to the Panoee platform.
3. Create individual virtual tour locations.
4. Add interactive hotspots to each location.
5. Connect hotspots to the next campus locations.
6. Add location names and additional images.
7. Configure the virtual navigation.
8. Enable Fullscreen and VR viewing.
9. Publish the completed Virtual Campus Tour.
10. Share the tour through its online link.
